# 대화의 회의실 현황을 한 줄 목록으로 — 회의 (2026-10-30)

- 참석: 리드(진행), QA, UI/UX 디자이너. 모두 에이전트예요. 회의 중에는 코드를 고치지 않았어요.
- 안건: 사용자 제안 "회의실 현황을 물으면 대화창에 안내 글 대신 회의실 카드를 한 줄씩 보여 주는 게 더 편하지 않나?"
- 결론: 두 사람 모두 찬성했어요. 다만 한 줄에서 바로 예약하지 않고, 아래 그림 카드는 저절로 펼치지 않는다는 조건이에요. 사용자가 권고안대로 구현을 정했어요(10/30).

## 지금 방식의 문제(코드로 확인)

| 문제 | 내용 |
|---|---|
| 날짜 어긋남 | "내일 현황"을 물으면 대화 카드는 내일 기준인데, 아래 그림 카드는 늘 오늘 기준이었어요 |
| 기준 시각 어긋남 | 아래 목록은 페이지에 들어올 때 한 번 불렀어요. 늦게 물으면 오늘이어도 두 쪽 상태가 달랐어요 |
| 질문에 답하지 못함 | "내일 빈 회의실 있어?"가 그날 전체 목록을 줬어요 |
| 읽기 힘듦 | 이름 칸이 좁아 "회의실 3A · 3층"이 두 줄로 깨지고, 10곳이면 20줄이었어요 |
| 누를 수 없음 | 줄이 글자뿐이었고, 꼬리는 "다시 써 주세요"였어요 |
| 쓰기 꺼짐 | 예약이 꺼진 모드에도 "'잡아 줘'처럼 말해 주세요"가 붙었어요(QA D-C03) |
| 중복 | 대화 카드와 그림 카드가 같은 내용을 다른 문구·순서로 보여 줬어요 |
| 빈 결과 | 없는 층을 물으면 빈 카드가 나왔어요 |
| 날짜 표기 | 답에 "2026-10-31"이 그대로 나왔어요 |
| 접히지 않음 | 현황 뒤에 다른 질문을 해도 펼친 목록이 남았어요 |

## 정한 것(구현함)

- **대화 현황 카드(variant `rooms-overview`)**: 회의실마다 누르는 한 줄이에요. 이름 · 층 · 정원 · [내 층] · [점검 중] / 상태 배지 / ›.
  - 상태 글은 그림 카드와 같은 함수(shared `roomStatusText`)예요.
  - 장비는 빼요. 자세히에서 봐요.
  - 정렬은 내 층 먼저, 층 번호, 이름 순이에요. 그림 카드와 같아요.
  - 처음엔 5줄이고 [N곳 더 보기]로 그 카드 안에서 펼쳐요.
  - 줄을 누르면 회의실 자세히가 물은 날짜로 열려요. 예약은 거기서 확인 시트를 거쳐요(ADR-03). 줄에는 예약 버튼이 없고 머리 라벨은 "안내"예요.
  - 화면 읽기: 목록(`ul/li`)이고, 줄마다 "회의실 3A, 3층(내 층), 정원 4명, 지금 비어 있어요 · …. 자세히 보기"로 읽혀요. 눌리는 높이는 44px 이상이에요.
  - 따로 그리지 못하는 화면을 위해 같은 내용을 글 칸(fields)에도 남겨요.
- **날짜와 빈 회의실**: 머리말과 답에 "10월 31일(토)"처럼 써요. 빈 회의실은 오늘이면 지금 빈 곳, 다른 날이면 그날 예약 없는 곳이에요. 없는 층은 "9층 회의실이 없어요"로 답해요.
- **꼬리**: 회의실 쓰기가 켜져 있으면 "회의실을 누르면 그날 일정을 보고, 확인 한 번으로 예약해요", 꺼져 있으면 "회의실을 누르면 그날 일정을 봐요. 예약은 그룹웨어에서 해요".
- **"모든 회의실"(그림 카드)**: 저절로 펼치지 않아요. 현황 카드의 [그림으로 모든 회의실 보기]를 눌렀을 때만 같은 날짜·조건으로 새로 불러(기준 시각을 맞춰요) 펼치고 그 자리로 넘겨요. 새 문장을 보내거나 대화를 지우거나 페이지를 떠나면 접어요.
- 서버 응답의 `showRooms`(10/30 오전에 더함)는 뺐어요. 펼칠 조건은 현황 카드 안(`card.overview.show`)에만 있어요.

## 시험

- 서버(`modules/rooms/chat.test.ts` '현황·장비 현황'): 한 줄 목록·정렬·날짜 표기·기준 시각, 내일 현황(예약 수)과 내일 빈 회의실(그날 예약 없는 곳), 없는 층, 응답에 예약자·회의 제목·가명 ID 없음, 묻기만으로는 plans·예약이 그대로, 쓰기 꺼짐 꼬리.
- 화면(로컬 Chrome 390×844로 확인): 처음엔 "모든 회의실" 칸 없음 → 현황 5줄 + [5곳 더 보기] → 10줄 → 줄을 누르면 자세히 시트 → [그림으로 보기]로 그림 카드 10곳이 펼쳐지고 제목이 위 막대 아래(64px)에 와요 → 새로 물으면 접힘 → "내일 빈 회의실"·"9층" 문구. 그동안 쓰기 요청은 0건이에요.
- 남은 것: 웹 컴포넌트 자동 시험은 jsdom 결정(A9) 뒤예요.
