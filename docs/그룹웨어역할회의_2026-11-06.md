# 이 앱이 그룹웨어 역할까지 하면 어떤 제약이 걸리나 — 회의 (2026-11-06)

- **참석**: 리드(진행·정리), 법·규정, 보안·인증, 아키텍처·제품, 시장·반대 검토(레드팀). 모두 에이전트예요. 코드는 고치지 않았어요.
- **안건**: 그룹웨어를 따로 두지 않고, 이 앱이 그룹웨어 역할(전자결재·근태 원장·조직도·캘린더·게시판·문서·메일·메신저)까지 하려면 어떤 제약이 걸리는지예요.
- **방식**: 네 담당이 따로 조사했고 리드가 합쳤어요.
- **출처와 한계**
  - 법령은 공개 자료 조사이고 법률 자문이 아니에요. 국가법령정보센터는 조문이 나오지 않아 2차 출처(casenote·korea.legal·itwiki)로 확인했어요.
  - 경쟁사 정보는 2026-11-06에 공식 페이지에서 다시 확인했어요.
- **맥락**: 같은 날 사용자가 휴가를 A안(신청·결재는 그룹웨어 전자결재, 앱은 신청 전 카드와 승인 뒤 반영만)으로 정했어요. 지금은 포트폴리오 심사를 앞두고 있어요.

## 결론

**네 명 모두 "그룹웨어 역할까지 하는 건 권하지 않는다"예요. 지금처럼 그룹웨어 옆에 붙어요.**

- **법은 막지 않아요.** 다만 결재나 근태의 원본을 맡는 순간 넷이 법적 의무가 돼요: 3년 보존, 고칠 수 없는 원본, 결재자 이름 표시, 인사팀의 전원 열람. 개발사는 수탁자로서 손해배상과 반환 책임까지 져요.
- **이 의무들이 앱의 뼈대와 정면으로 부딪혀요.**
  - 7일 보관(ADR-21)
  - 개인 인사 자료는 본인 화면만(ADR-18)
  - 이름 비노출
  - 바깥 원본 + 어댑터(ADR-05)
  - 서버 한 대(ADR-01)

  지금 이 프로젝트의 특색인 "AI를 써도 사고 나지 않는 구조"의 상당 부분이 이 선들에 기대고 있어요.
- **1인 개발사가 갖추기 어려운 것들이 따라와요.**
  - 결재 위·변조 방지(덧붙이기만 하는 이력과 해시 체인)
  - 결재선·대결·전결 권한 모델과 관리자 권한 나누기
  - 인증(ISMS·CSAP)
  - 수년 보관 백업·복원
  - 서버 두 대와 무중단 운영
- **시장은 이미 싸고 꽉 찼어요.**
  - 하이웍스 Core는 100명까지 0원이고, 그룹웨어는 첫해 2,000원이에요.
  - 다우오피스는 5인 이하 무료이고, 카카오워크 Mini는 2,400원이에요.
  - 근태·휴가 결재만 하는 시프티는 3,500~4,000원에 ISO 27001을 갖췄어요.
  - 그룹웨어가 되면 기능 수 싸움이 되고, "그룹웨어 미니판"이라는 인상 때문에 특색이 더 옅어져요.

| 급여·ERP | 없음(급여 공제는 거부) | 계산·전표 | PRD 범위 밖 | 매우 큼 |

표 밖에서 같이 바뀌는 것도 있어요.
- `링크만` 스위치는 물러날 곳이 없어서 뜻을 잃어요.
- 결재 엔진을 여러 모듈이 같이 쓰게 돼서 "모듈은 자기 표만" 선과 부딪혀요.
- 표가 30~40개 늘어요(어림값). 더 큰 변화는 성격이에요. 지금 표는 대부분 7일 뒤 지우는데, 몇 년 남고 고칠 수 없는 원장이 생겨요.
- 기록을 묶는 가명 ID는 회전할 수 없는 비밀 값에 매여 있어서, 원장은 사번으로 묶어야 해요.
- 회사마다 한 벌씩 띄우니(ADR-23), 1인이 N벌을 24시간 지켜야 해요. 그룹웨어 제품마다 다른 자료 이관 도구도 필요해요.

## 4. 시장·반대 검토

- **그룹웨어까지 하자는 쪽의 약점**
  - 값이 0~2,000원까지 내려와 있고, 경쟁사는 인증과 구축형을 갖췄어요.
  - 구매팀의 첫 질문은 "개발자가 아프면요?"일 거예요.
  - 결재 하나만 해도 범위가 폭발해요. 결재선, 대결, 양식, 보존, 메일, 조직도, 52시간 근태가 줄줄이 따라와요.
  - 비교 기준이 하이웍스가 되면서 특색이 더 옅어져요.
- **옆에 붙자는 쪽의 약점**
  - 그룹웨어 없는 회사에서는 휴가가 반쪽이에요.
  - "결국 링크만 주는 앱 아니냐"는 질문을 받아요.
  - 그룹웨어 AI가 분장표 근거 답을 흉내 낼 수 있어요.
  - 시연용 가상 그룹웨어를 다듬을수록 "그럼 그룹웨어를 만든 거냐"는 역공이 와요.
  - 장부가 바깥에 있어서 도입이 쉬운 만큼 떠나기도 쉬워요.
- **중간 길(10~50명용 가벼운 결재 + 근태)**은 이미 채워졌어요. 시프티 3,500~4,000원(ISO 27001, 30인 미만 무료 지원), 플렉스 Core HR, 하이웍스(결재 → 근태 자동 반영)가 있어요.

| 근태·연차 원장 | 위에 더해 날마다 근로시간, 정정 이력, 본인 열람·정정, 퇴직 뒤 3년 | ADR-05·18·24·21, 백업·무중단 필수 | 큼 | 하지 않아요 |
| 결재 일반·인사 기록·전부 | 양식 편집기, 고유식별정보 암호화, 메일·메신저 인프라 | 제품 위치 전체 | 매우 큼 | 하지 않아요 |

## 권고 (리드 정리)

1. **그룹웨어 역할은 맡지 않고 "옆에 붙기"를 유지해요(A안 그대로).** 포트폴리오와 발표에서도 "그룹웨어를 대신한다"고 말하지 않아요.
2. **"링크만 주는 앱"이라는 질문에는 링크 앞의 판단으로 답해요.** 시연의 주인공을 셋으로 세워요.
   - 분장표 근거 담당 카드: 근거가 없으면 카드를 만들지 않아요.
   - 휴가 신청 전 카드: 남은 연차, 걸린 일, 걸린 일이 없는 가까운 날 제안.
   - 지시문 주입 시험: 공격 문장을 넣어도 쓰기 0건.

   카페·탕비실·MCP는 부록으로 돌려요.
3. **가상 그룹웨어는 지금 수준에서 더 다듬지 않아요.** "다른 회사 제품 자리" 띠를 유지하고, 시연에서는 30초 안에 지나가요. 설명은 "어댑터만 바꾸면 하이웍스·다우오피스로 갈아 끼운다"를 보여 주는 도구로 해요.
4. **실제 사업 단계라면**
   - 파일럿 회사 그룹웨어와 실제 연동 하나를 먼저 끝내요.
   - 그룹웨어가 없는 회사는 결재 원본을 시프티·플렉스 같은 저가 근태 SaaS에 두고 그 옆에 붙어요(각 API 범위는 확인 필요).
   - 공급자가 1명이라는 위험은 로드맵과 소스코드 임치 같은 계약 장치로 답해요.
5. **할 만한 작은 것**: 그룹웨어 없는 회사용 회의실 원본 켜기(방 관리 화면). 연차 사용 촉진 통보는 선택이에요.

## 결정을 가르는 질문 (사용자)

1. 파일럿 회사에 그룹웨어가 있나요? 있다면 어느 제품이고, 결재·근태 API가 열려 있나요?
2. 결재 장부를 위해 7일 보관·본인만·이름 비노출 원칙을 그 영역에서 풀 수 있나요? 풀 수 없다면 그룹웨어 역할은 원칙상 불가능해요.
3. 그룹웨어 AI가 분장표 근거 답을 흉내 내면 우리에게 무엇이 남나요? 회의의 답은 "AI 쓰기 경계를 시험으로 증명하는 구조"이고, 이게 대표 메시지가 돼야 해요.
