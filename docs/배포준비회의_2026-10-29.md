## 한눈에

1. **배포 구성은 "이미지 하나 + 한 대 + 관문"으로 정했어요(7명 모두).**
   - 같은 컨테이너의 Fastify가 API와 웹 화면 파일을 같이 줘요.
   - 사내 관문은 TLS·HSTS·경로 거르기·로그 가리기·점검 화면만 맡아요.
   - DB는 관리형 PostgreSQL 17이에요.
   - CDN은 쓰지 않아요.
2. **지금 코드로는 운영 이미지를 만들 수 없어요.**
   - 서버를 돌리는 `tsx`가 개발용 의존성이라, 운영 설치에서 빠져요.
   - Dockerfile, `.dockerignore`, 웹 파일을 내보내는 길이 없어요.
   - 운영에서도 `.env`를 읽어요(확인).
3. **보안 구멍 셋을 먼저 막아요.**
   - 서버를 다시 띄우거나, 세션이 8시간을 넘거나, 로그아웃한 뒤에는 쉬던 사람도 비밀번호 없이 SSO로 다시 들어와요(확인). → 로그인할 때마다 `max_age`(쉬는 시간)를 붙여요.
   - 세션 쿠키에 `__Host-`가 없어요(확인).
   - TRUST_PROXY를 비우거나 `10.0.0.0/8`을 넣어도 운영이 떠요(확인).
4. **배포할 때마다 모두 로그아웃돼요(세션이 메모리에 있어서요).**
   - 파일럿 1단계는 세션 표 없이 버텨요. 대신 배포는 화·목 19:30에 하고, 예고 띠와 "앱이 새로 바뀌었어요" 문구를 둬요.
   - 세션 표(앞선 F1, 2~3 업무일)는 2단계 전에 해요. 낮 재시작이 잦아지면 더 일찍 당겨요.
5. **화면은 "흰 화면·영어 오류·옛 화면"을 막는 게 먼저예요.**
   - `#root` 안에 뼈대를 넣고, 오류 경계를 둬요.
   - 배포 중에는 한국어 문구를 보여 줘요.
   - 새 버전이 나오면 띠를 띄워요.
   - 옛 브라우저용 대체 값을 넣고, 폰 입력 칸은 16px로 맞춰요.
6. **시연은 파일럿과 완전히 떼요.**
   - 다른 주소·다른 비밀·다른 DB를 쓰고, 사내망 허용 목록 뒤에 둬요.
   - 시연 자료는 매일 밤 비워요.
   - "여러 사람이 같은 가상 직원을 같이 써요" 경고를 띄워요.
7. **파일럿 1단계는 AI 없이(규칙만) 시작해요(7명 모두 찬성).**
   - 무보관 계약이 늦어도 파일럿이 멈추지 않아요.
   - PRD 문장을 고치는 일은 사용자 결정이에요.

| 비밀·로그 | 비밀은 사내 비밀 저장소에서 env로 넣어요. 로그는 stdout JSON을 사내 수집기에 7일 둬요 | 이미지·CI 로그에는 비밀을 두지 않아요 |
| 시연 | 같은 이미지를 다른 하위 도메인에 띄워요(`DESK_MOCK_LOGIN=true`, PGlite, DB 없음) | 사내망·IAP 허용 목록 뒤에 두고, noindex를 붙이고, 배포 때마다·매일 밤 비워요. 롤링 배포는 하지 않아요 |

- 주소: 전용 하위 도메인의 **루트 경로**에 둬요(예: `desk.회사도메인`). `PUBLIC_BASE_URL`은 경로를 받지 않고, `__Host-` 쿠키와 상대 주소 요청이 출처 하나를 전제해요.
- 인증서: 파일럿은 공개 도메인 아래 이름과 공인 인증서를 써요. 바깥 IAP와 나중의 claude.ai MCP가 사내 CA를 믿지 않아서예요. 안에서는 split DNS를 써요.
- 용량: 150명 중 동시 30명이면 직접 조작과 폴링을 합쳐 5 req/s 안팎이에요. 1 vCPU·1GB·풀 10으로 넉넉해요. 병목은 처리량이 아니라 메모리 상태(C1)와 IdP 명단 갱신(C3)이에요.
- 두 대·무중단 배포는 운영 단계에서 해요. 조건은 세션 표(앞선 F1), 보관 잡 잠금(앞선 A6), 운영 설정 판 번호 다시 읽기, MCP 인가 코드 표예요.

## 6. 배포하면 생길 문제와 대처
