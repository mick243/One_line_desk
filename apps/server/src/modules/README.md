# 모듈

공통 바닥(인증·세션·감사 로그·AI 게이트웨이·plan) 위에 모듈 다섯을 얹어요(ADR-01). 모듈은 자기 표와 쓰기 경로만 가져요. 다른 모듈 표는 읽지도 쓰지도 않아요.

| 폴더 | 기능 | 하는 일 | 만드는 날 | 근거 |
|---|---|---|---|---|
| `navi/` | F1 담당 안내 | 분장표 후보 검색, LLM은 후보 번호만 고름, "여기로 물어보세요" 카드, "틀렸어요" 기록, S5 목록 + 분장표 파일 다시 올리기 | 4~5일 | ADR-09, R8·R9 |
| `notices/` | F1 공지 찾기 | 허용 게시판 사본 색인, 제목·게시일·원문 링크만(요약 꺼짐), MCP `notices_search` | 5일, MCP 9일 | ADR-09, ADR-14 |
| `rooms/` | F2 회의실 | 모의 장부, 겹침 제약, 후보·대안, plan과 확인 시트, 내 예약·취소, MCP `rooms_find_free` | 6일, MCP 9일 | ADR-06, ADR-03, ADR-14 |
| `pantry/` | F3 같이 채워요 | 공개 미리보기 게시, +1·거두기, 같은 상품 표시, 총무 합치기·되돌리기, 주문안·주기(`order/`) | 7~9일 | ADR-04, ADR-07, ADR-08 |
| `mcp/` | 읽기 전용 MCP | OAuth 인가 서버(PKCE·등록 클라이언트만), `/mcp` 도구 둘, 동의 시트, 연결 끊기·퇴사 자동 끊김, 앱 확인 링크 | 9일 | ADR-14, ADR-15, M1~M7 |

도구 정의는 먼저 `src/core/tool-registry.ts`에 있어요. 모듈 사이 기능은 `src/core/services.ts`로만 주고받아요.
